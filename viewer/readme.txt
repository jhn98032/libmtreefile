Viewer GUI.


Dependencies
============



Make sure that you have all dependencies installed.

On Debian/Ubuntu/Mint:

    # sudo apt-get install qt5-qmake qtbase5-dev 

or for qt6:
   

    # sudo apt install qt6-base-dev

On Redhat/Centos:

    # sudo yum install qt5-designer qt5-devel

On FreeBSD:

    # pkg install qt5
    # pkg install gcc
